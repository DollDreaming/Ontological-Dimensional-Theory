# 존재론적 차원이론(ODT) 위키

존재가 스스로를 확정하고, 잇고, 넓혀 가는 과정을 1성부터 9성까지 아홉 단계로 해석하는 존재론적 차원이론(Ontological Dimensional Theory, ODT)의 공개 위키입니다.

**위키 바로 가기: [dolldreaming.github.io/Ontological-Dimensional-Theory](https://dolldreaming.github.io/Ontological-Dimensional-Theory/)**

## 둘러보기

|---|---|

| [1~9성](https://dolldreaming.github.io/Ontological-Dimensional-Theory/dimensions/) | 점 · 선 · 면 · 입체 · 다층 · 방향 · 중심 · 반향 · 종합 |
