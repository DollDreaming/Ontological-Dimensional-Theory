# 존재론적 차원이론(ODT) 위키

존재가 스스로를 확정하고, 잇고, 넓혀 가는 과정을 1성부터 9성까지 아홉 단계로 해석하는 존재론적 차원이론(Ontological Dimensional Theory, ODT)의 공개 위키입니다.

**위키 바로 가기: [dolldreaming.github.io/Ontological-Dimensional-Theory](https://dolldreaming.github.io/Ontological-Dimensional-Theory/)** · 영문판: [/en/](https://dolldreaming.github.io/Ontological-Dimensional-Theory/en/)

## English

A public wiki of the Ontological Dimensional Theory (ODT) by Seo Won-Yong, which interprets how existence establishes, connects and extends itself in nine stages, from the 1st to the 9th dimension.

- **English edition: [dolldreaming.github.io/Ontological-Dimensional-Theory/en/](https://dolldreaming.github.io/Ontological-Dimensional-Theory/en/)**
- The Korean edition is authoritative; the English edition is its translation. The author's quotations are translated, with the Korean original in a note.
