# 학문 통합

**모든 학문은 존재의 서로 다른 성을 관찰하는 서로 다른 창이다.** 이렇게 보면 학문 사이의 불일치는 '성 사이의 시야 차이'로 설명된다. <span class="st st-int">대응</span>

## 성별 학문 대응

| 성 | 대응 학문 | 다루는 것 |
|---|---|---|
| 1 기준 | 수학적 존재론, 논리학 | '무엇이 존재하는가'의 최소 정의 |
| 2 관계 | 네트워크 이론, 물리학(상호작용) | 존재 간 연결, 힘, 통신 |
| 3 영향의 장 | 전자기학, 사회적 영향 이론 | 관계의 장, 파급 효과 |
| 4 구조 | 화학, 생물학, 시스템 이론 | 형태·조직·패턴의 생성 |
| 5 통합 | 인지과학, 생명 시스템, 정보 통합 | 다층적 존재 통합체(생명) |
| 6 방향성 | 진화론, 경제학, 동역학 | 목적, 경향, 에너지 흐름 |
| 7 중심선 | 심리학, 기억 이론, 자아 모델 | 정체성, 기억, 중심성 |
| 8 반향·인지 | 의식 연구, 신경과학, 인공지능 | 반응·피드백·의식의 발생 |
| 9 정의 | 철학, 언어학, 인문학 | 의미와 가치의 종합적 해석 |

크게 보면 물리학은 1~4성, 생명과학·심리학은 5~8성, 철학·예술은 9성을 보고, 사회·정보과학은 2~7성을 오가는 상호작용을 본다.

## 통합 함수

모든 학문이 다루는 현상은 다음 일반 함수로 나타낼 수 있다.

$$
E_n(t) = \Phi_n\big(E_{n-1}(t), \dots, E_1(t),\, S(t)\big)
$$

- $E_n(t)$ — n성의 존재 상태(학문이 설명하는 대상이 놓인 성)
- $\Phi_n$ — 그 성의 생성·전이 함수(학문의 법칙)
- $S(t)$ — 자극·환경 변수(경험적 세계)

여기서 $S(t)$는 그 대상이 놓인 환경이다. 어느 성의 대상이든 제 안에 1~9성을 가지므로, 자극은 그 대상의 8성 자리에서 들어온다. → [8성 · 반향](../dimensions/8-resonance.md)

## 프랙탈 통합성

각 학문도 자기 안에서 다시 1~9성으로 나뉜다. 물리학 하나만 보아도 양자 상태의 확정(1성) → 상호작용·힘(2성) → 장(3성) → 원자 같은 구조(4성) → 분자·생명 전구체 같은 통합(5성) … 으로 다시 펼쳐진다. 각 학문은 전체의 축소 모형이고, 전체 지식은 부분이 자기유사적으로 되풀이되며 넓어진다.

## 통일된 개념 <span class="st st-hyp">가설</span> { data-toc-label="통일된 개념" }

- **시간** — 물리학의 공간적 시간과 심리학의 인지적 시간이 모두 위상 정렬의 속도로 환원된다.
- **에너지** — 물리량만이 아니라 존재의 위상 장력(phase tension)이다. 생명과 의식의 에너지도 같은 형태로 기술할 수 있다.
- **정보** — 양자정보·생명정보·언어정보·의식정보는 위상 정렬률을 나타내는 방식이 다를 뿐 같은 구조다.
