# 정보이론에서의 해석

**ODT에서 '존재한다'는 것은 정보가 생겼다는 뜻이다.** 1~9성은 정보의 생성 → 전파 → 구조화 → 통합 → 피드백 → 의미화로 이어지는 단계로 읽힌다. <span class="st st-int">해석</span>

핵심 관점은 "존재 = 정보의 위상적 구조화"다. 1성의 존재는 정보이론으로 보면 엔트로피가 0보다 크다는 것, 즉 정보가 발생했다는 뜻이다.

## 성별 정보 행위

| 성 | 정보역학적 대응 | 정보 행위 |
|---|---|---|
| 1 점 | 존재의 확정 비트(0/1), 정보의 발생 | 정보 생성(Information Birth) |
| 2 선 | 존재 간의 관계, 정보 연결·링크 | 정보 결합·전달(Coupling) |
| 3 면 | 관계의 장, 네트워크 정보 흐름, 상호의존 | 정보 확산·파동(Propagation) |
| 4 입체 | 영향의 구조화, 정보 패턴, 의미 구조 | 패턴 인식·질서화(Patterning) |
| 5 다층 | 통합 멀티레이어 네트워크, 상위 엔트로피 | 다층 통합(Integration) |
| 6 방향 | 방향성, 정보 흐름의 벡터, 목적 함수 | 정보 에너지 흐름(Flow, Gradient) |
| 7 중심 | 중심 궤적, 메모리, 정보 압축, 평균 경로 | 정보 누적·압축(Memory) |
| 8 반향 | 반향·인지, 피드백 루프, 자기정보(Autopoiesis) | 정보 자기참조(Feedback) |
| 9 종합 | 종합적 정의, 정보의 해석, 엔트로피 최소 상태 | 정보 해석·의미화(Meaning Extraction) |

## 정보역학적 시간 <span class="st st-hyp">가설</span> { data-toc-label="정보역학적 시간" }

ODT의 시간은 위상 정렬의 축, 즉 변화의 정도다. 정보이론으로 보면 엔트로피의 시간 변화율(정렬률)이다.

- 정렬(질서↑) → 정보 압축 → 시간의 흐름이 느려짐
- 혼돈(무질서↑) → 정보 확산 → 시간의 흐름이 빨라짐

시간은 절대적이지 않고, 정보 정렬 속도에 따라 흐르는 상대적 변수가 된다. → [시간](../principles/time.md)

## 존재의 장 = 정보 흐름의 장

3성의 장은 에너지 분포가 아니라 정보의 흐름·전달 확률 분포로 읽히며, 정보 흐름의 보존식이 된다.

$$
E_3(x,t) = \nabla\cdot I(x,t) + \frac{\partial I}{\partial t}
$$

여기서 $I$는 정보이며, 식은 '존재의 위상 변화 = 정보의 전이'를 뜻한다. 존재의 장은 정보의 상호작용과 변환이 일어나는 위상적 매질이 되고, 결국 에너지 흐름과 정보 흐름은 구분되지 않게 된다.

## 엔트로피와 의미의 순환

| 성 | 엔트로피 | 존재론적 의미 |
|---|---|---|
| 1~3성 | 높음 (다양한 가능성) | 생성과 확산 |
| 4~6성 | 중간 (질서화 중) | 구조·통합·방향성 |
| 7~9성 | 낮음 (정보 압축) | 중심·인지·정의 |

정보역학으로 보면 존재의 진화는 엔트로피 감소를 통한 정보 압축, 곧 의미가 형성되는 과정이다.

## 8성과 프랙탈의 정보적 본질

- **8성 = 자기지시 시스템, 곧 오토포이에시스** — 정보역학으로 보면 8성은 자기지시 시스템(self-referential system), 즉 오토포이에시스(autopoiesis)다. 시스템이 자신에 대한 정보를 피드백해 중심선(7성)을 갱신하고 외부 자극을 의미(9성)로 바꾸며, 본편은 이것이 의식을 자기정보 처리(Self-Information Processing)로 보는 모델과 같다고 적는다. 정보에 대한 정보(Information about information), 곧 메타정보가 형성되는 차원이다.
- **프랙탈 = 정보의 자기압축** — 한 구조를 다시 1~9성으로 펼친다는 것은, 그 구조 안의 정보가 다시 생성·전달·의미화를 되풀이한다는 뜻이다. 홀로그램적 정보 세계 모형과 맞닿는다.

> 양자역학 = 미시적 정보역학, 상대성이론 = 거시적 정보역학, 그리고 존재론적 차원이론 = 양자와 상대성을 아우르는 정보의 위상론적 생성 구조라 할 수 있다.
