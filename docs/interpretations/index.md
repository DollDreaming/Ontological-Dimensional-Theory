# 해석

**ODT는 같은 1~9성 구조로 여러 분야의 개념을 읽는다.** 이 절의 짝짓기는 모두 대응이며, 각 분야의 기존 이론을 부정하거나 대체하려는 것이 아니다. <span class="st st-int">대응</span>

> 이 해석은 기존의 설명 틀과 상충하거나 배제하려는 것이 아니라, 본 논문에서 분류하고 재정의한 각 성이 가지는 개념적 정의를 통해 세상을 바라보는 의미를 다시 구성하고자 한다.
>
> — 본편 「서론」

| 분야 | 한 줄 요지 |
|---|---|
| [물리학](physics.md) | 시공간을 결과로, 존재의 위상을 원인으로 다시 놓는다 |
| [정보이론](information.md) | 존재한다는 것은 정보가 생겼다는 뜻이다 |
| [의식과 자아](mind.md) | 자아는 누적된 중심(7성), 의식은 그 중심의 반향(8성)이다 |
| [학문 통합](disciplines.md) | 모든 학문은 서로 다른 성을 관찰하는 서로 다른 창이다 |
| [인공지능](agi.md) | 1~9성은 인공지능이 자기조직·자기지시를 거쳐 의식적 통합 상태로 가는 경로다 |
