# 용어집

**ODT를 읽는 데 필요한 말들이다.** 한 말은 한 뜻으로만 쓴다. 괄호 안은 영문판에서 쓰는 말이다.

객체 (object)
:   존재와 대상. ODT가 해석하는 모든 것을 가리킨다.

계층 (level)
:   프랙탈과 순환에서의 위아래. 한 계층의 9성이 더 큰 계층의 1성이 된다. → [연결 구조](principles/linked-structure.md)

공명과 상쇄 (resonance, cancellation)
:   두 객체의 위상 차이에 따라 연결이 강해지거나(공명) 약해지는(상쇄) 것. → [2성](dimensions/2-line.md)

구조적 선언 (structural declaration)
:   수식의 출발점. 각 성의 위상적 관계와 작동 방향을 나타낸다. 지금은 계산식으로 세워 확인하는 단계로 넘어가고 있다. → [열린 과제](research/open-problems.md)

근원점 (source point, σ₀)
:   3성에서 영향의 장이 퍼져 나가는 점. → [3성](dimensions/3-plane.md)

기준정의 · 의미정의 · 종합정의 (reference, semantic, holistic definition)
:   1성·5성·9성이 맡는 세 정의. → [핵심 원리](principles/index.md#tiers)

만물해석키
:   저자가 ODT의 출발점을 부르는 말. 만물을 같은 구조로 풀어 보는 열쇠라는 뜻이다.

반향과 반사, 투사 (resonance and reflection, projection)
:   7성의 중심선과 잔흔이 자극에 진동해 되울리는 것(반향·반사)과 밖으로 내보내는 것(투사). 8성의 작용이다. → [8성](dimensions/8-resonance.md)

배열 규칙 (arrangement rule, A)
:   3성의 장들을 단순한 합이 아니라 특정 패턴과 규칙으로 입체적 구조로 배열하는 규칙. 1성의 진폭 A와 다른 기호다. → [4성](dimensions/4-volume.md)

성 (dimension)
:   존재가 쌓여 올라가는 단계, 1성부터 9성까지. 성마다 기하학적 축이 하나씩 더해지되 앞선 축 위에 쌓인다. → [핵심 원리](principles/index.md)

순환 구조 (circular structure)
:   9성의 정의가 다음 해석의 1성이 되는 구조. → [연결 구조](principles/linked-structure.md)

시간 (time)
:   변화, 곧 공간의 엔트로피 변화. 공간과 나란히 놓인 축이 아니다. 수식의 $t$는 변화를 세는 매개 변수다. → [시간](principles/time.md)

영향의 장 (field of influence)
:   관계들이 모여 주변에 미치는 영향의 범위와 파동적 특성. 장(場)은 6성의 장력(張力)과 다른 말이다. → [3성](dimensions/3-plane.md)

위상 (phase, φ)
:   존재가 정렬된 상태. 1성의 φ가 그 가장 작은 모습이고, 2성에서 공명과 상쇄를 정하며, 그 정렬의 변화가 시간이다.

위상적 누적 (topological accumulation, phase overlap, ⨁)
:   단순한 합이 아니라 위상이 겹쳐 쌓이는 연산. 성 사이의 생성이 이것이다. → [핵심 원리](principles/index.md#topological-accumulation)

자극 (stimulus, S)
:   8성에서 7성에 작용하는 안팎의 영향이나 정보. 그 정체는 에너지다. 이 이론은 안의 자극과 밖의 자극을 가르지 않는다. → [8성](dimensions/8-resonance.md)

잔흔 (residual trace)
:   7성에서 덜 겹쳐 흐리게 남은 궤적. 선을 말할 때는 잔흔선이라 한다. → [7성](dimensions/7-center.md)

장력 (tension, 𝒯)
:   5성 통합체 안의 층위별 가중치나 상태 사이의 비대칭에서 생기는 내부 압력. 6성 방향성의 원동력이다. → [6성](dimensions/6-flow.md)

종합 연산자 (synthesis operator, Ω)
:   1~8성을 처리·해석·압축해 객체의 총체적 정의를 끌어내는 연산. → [9성](dimensions/9-synthesis.md)

중심선 (center line)
:   7성에서 많이 겹쳐 선명하게 드러나는 궤적. 객체의 기억·역사·정체성에 해당한다. → [7성](dimensions/7-center.md)

중첩과 누적 (overlap, accumulation)
:   중첩은 겹치는 일, 누적은 그 겹침이 쌓인 결과다. 같은 생성 과정의 두 면이다. 양자역학의 중첩(superposition)은 '양자 중첩'이라 따로 적는다.

진폭 (amplitude, A)
:   객체가 존재할 때 가지는 잠재적 영향력의 최소 크기. → [1성](dimensions/1-point.md)

층 (tier)
:   아홉 성의 묶음. 형이하 층(2~4성), 형이상 층(6~8성), 정의(1·5·9성). → [핵심 원리](principles/index.md#tiers)

층위 (layer)
:   5성에서 한 존재를 이루는 서로 다른 면(사회·감각·생물 등). → [5성](dimensions/5-multilayer.md)

통합체 (integrated whole)
:   서로 다른 층위의 구조들이 중첩·통합된 전체. 통합은 5성, 종합은 9성의 말이다. → [5성](dimensions/5-multilayer.md)

프랙탈 구조 (fractal structure)
:   어느 성이든 그 안에 다시 1~9성의 내부 구조를 갖는 계층적 재귀. → [연결 구조](principles/linked-structure.md)
