# 용어집

**ODT를 읽는 데 필요한 말들이다.** 본편 v9.4의 용어를 그대로 쓰고, 그 뒤에 저자가 쓰기 시작한 말은 따로 표시했다.

객체
:   존재와 대상. ODT가 해석하는 모든 것을 가리킨다.

공명과 상쇄
:   두 객체의 위상 차이에 따라 연결이 강해지거나(공명) 약해지는(상쇄) 것. → [2성](dimensions/2-line.md)

구조적 선언
:   본편 수식의 성격. 수리적 계산을 위한 방정식이 아니라, 각 성의 위상적 관계와 작동 방향을 나타내는 선언이다.

만물해석키
:   저자가 ODT의 성격을 부르는 말(v9.4 이후 저자 용어). 수식보다 논리로 먼저 만물을 해석하는 틀이라는 뜻이다.

반향과 투사
:   7성의 중심선이 자극에 진동해 되울리는 것(반향)과 밖으로 내보내는 것(투사). → [8성](dimensions/8-resonance.md)

성
:   존재가 쌓여 올라가는 단계. 본편은 '성(차원)'이라 적으며, 독립축이 아니라 앞 성들의 중첩으로 생긴 위상 단계다.

순환 구조
:   9성의 최종 정의가 다음 해석의 1성이 되는 구조. → [연결 구조](principles/linked-structure.md)

영향의 장
:   관계들이 모여 주변에 미치는 영향의 범위와 파동적 특성. → [3성](dimensions/3-plane.md)

위상 (φ)
:   객체의 정렬 상태. 2성에서 공명과 상쇄를 정하고, 그 정렬이 시간의 바탕이 된다.

위상적 누적 (⨁)
:   단순한 합이 아니라 위상이 겹쳐 쌓이는 연산. → [핵심 원리](principles/index.md)

잔흔
:   7성에서 선택되지 않았거나 누적이 적었던 궤적. → [7성](dimensions/7-center.md)

장력 (𝒯)
:   5성 통합체 안의 층위별 가중치나 상태 사이의 비대칭에서 생기는 내부 압력. 6성 방향성의 원동력이다. → [6성](dimensions/6-flow.md)

종합 연산자 (Ω)
:   1~8성을 처리·해석·압축해 객체의 총체적 정의를 끌어내는 연산. → [9성](dimensions/9-synthesis.md)

중심선
:   7성에서 반복해 선택되어 선명하게 드러나는 궤적. 객체의 기억·역사·정체성에 해당한다. → [7성](dimensions/7-center.md)

진폭 (A)
:   객체가 존재할 때 가지는 잠재적 영향력의 최소 크기. → [1성](dimensions/1-point.md)

통합체
:   서로 다른 구조들이 여러 층위로 중첩·통합된 전체. → [5성](dimensions/5-multilayer.md)

프랙탈 구조
:   어느 성이든 그 안에 다시 1~9성의 내부 구조를 갖는 계층적 재귀. → [연결 구조](principles/linked-structure.md)
