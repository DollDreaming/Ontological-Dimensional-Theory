# 5성 · 다층 (Multilayer Layer System)

**입체들의 중첩 → 통합체.** <span class="st st-def">정의</span>

## 정의

4성에서 생긴 구조들이 여러 층위(Layer)로 중첩되고 통합되는 차원이다. 단일 구조가 아니라 생명, 의식, 사회, 감각 등이 서로 결합해 하나의 다층적 체계를 이룬다.

## 구조적 선언

$$
E_5(t) = \sum_k W_k(t)\, E_k(t)
$$

- **$E_5(t)$** — 다층적으로 통합된 존재(총체적 실체)의 상태.
- **$E_k(t)$** — 통합에 참여하는 k번째 층위의 구조 속성. 사회적·감각적·생물학적 층위 등이 여기에 해당한다.
- **$W_k(t)$** (층위 가중치) — 각 층위의 상대적 중요성 또는 작동 강도. 이 가중치에 따라 통합체 안에서 층위의 영향력이 정해진다.
- **$\sum_k$** (통합·중첩 연산자) — 여러 층위가 가중치를 반영해 총체를 이룬다.

## 해석

> 객체는 어떤 조합으로 이루어져 통합적인 의미를 이루는가?

인간의 오감처럼 서로 다른 층위의 자극이 하나로 통합·중첩되어 공감각을 이루는 것, 또는 한 객체의 사회적 역할·생물학적 구성·화학적 반응처럼 서로 다른 층위의 구조들이 중첩·융합되어 하나의 총체적 실체를 만드는 것과 같다.

## 특징과 확장

5성은 시스템적 통합의 차원으로, 단일 구조를 넘어 전체의 관점에서 존재를 보게 한다. 이후 6성에서 방향성과 가능성으로 드러날 기반이 된다.

본편의 고차원 보충해설은 테서랙트 구조와 셀 애니메이션을 예로 들며, 인간을 5성으로 해석하면 양자역학적·전기화학적·생물학적·인지사회적 세계가 종합된 합으로 정의된다고 적는다.

!!! warning "현행 읽기 · 개정 중"
    5성은 **서로 다른** 구조들이 함께 있을 때 선다. 같은 종류의 층끼리 겹치면 5성은 4성으로 되돌아간다. 여기서 '같은 종류'의 기준은 아직 정하는 중이다. → [열린 과제](../research/open-problems.md#falsification)

## 여러 분야에서의 대응 <span class="st st-int">해석</span> { data-toc-label="여러 분야에서의 대응" }

| 분야 | 5성의 대응 |
|---|---|
| 물리학 | 복합 시스템, 얽힘(entanglement), 위상 상태 |
| 끈 이론 | M-이론의 5-브레인, 다층 시공간 |
| 정보이론 | 통합 멀티레이어 네트워크, 상위 엔트로피 — 다층 통합(Integration) |
| 자아 | 인지·감정·기억의 통합체 |
| 학문 | 인지과학, 생명 시스템, 정보 통합 |
| 인공지능 | Multi-modal fusion, System integration |
