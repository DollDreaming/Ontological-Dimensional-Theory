# 2성 · 선 (Connection Line)

**점들의 연속적 중첩 → 관계.** <span class="st st-def">정의</span>

## 정의

객체 간의 선적 연결, 즉 점과 점이 관계를 맺고 상호작용하는 차원이다. 단순한 "있음/없음"을 넘어 두 존재가 어떻게 연결되는가를 설명한다.

## 구조적 선언

$$
E_2(t) =
\begin{cases}
A_i(t)\,A_j(t)\cos\big(\varphi_i(t)-\varphi_j(t)\big), & E_{1i}(t)\neq 0 \ \text{그리고}\ E_{1j}(t)\neq 0 \\
0, & E_{1i}(t)=0 \ \text{또는}\ E_{1j}(t)=0
\end{cases}
$$

- **$E_2(t)$** — 시간 t에서 두 객체 i와 j 사이의 연결 강도.
- **$E_{1i}(t),\,E_{1j}(t)$** — 연결에 참여하는 두 객체의 존재 상태. 연결은 두 객체가 모두 있을 때만 성립한다.
- **$A_i(t)A_j(t)$** (상호작용 강도) — 두 객체의 진폭이 결합된 최대 상호작용 가능성. 1성의 $A(t)$에서 나온다.
- **$\varphi_i(t)-\varphi_j(t)$** (위상 차이) — 두 객체의 최소 정렬 상태 사이의 차이. 이 차이가 공명(강화) 혹은 상쇄(약화)를 결정한다.

## 해석

> 객체와 객체는 어떻게 관계를 맺는가?

관계의 방향성과 강도는 물리적 연결을 넘어 정보·의미·작용을 전달하는 매개가 된다. 관계가 확립되는 순간, 1성의 최소 변수(A와 φ)의 상호작용이 공명 또는 상쇄라는 2성의 상태로 드러난다.

## 특징과 확장

위상 차이에 따라 공명 혹은 상쇄가 일어나며, 이 위상 차이의 정렬은 [시간해석](../principles/time.md)에서 말하는 '위상 정렬의 축'을 이루는 핵심 조건이다. 2성은 상호작용의 기본 단위로서 이후 모든 성의 토대가 되며, 사회적·심리적 관계망의 모델링에도 그대로 적용할 수 있다.
