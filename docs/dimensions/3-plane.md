# 3성 · 면 (Field Plane)

**선들의 중첩 → 영향의 장.**

## 정의

선들이 모여 이루는 면적 구조, 즉 존재가 주변에 미치는 영향의 장(場, Field)이다. 관계(2성)에서 넓어져, 관계들이 모여 이루는 영향 범위와 파동적 특성을 설명한다.

## 구조적 선언

3성의 영향장 함수는 2성의 시간적 변화와 공간적 분포로 정의한다.

$$
E_3(x,t) = \partial_t E_2(x,t) + \nabla E_2(x,t)
$$

- **$E_3(x,t)$** — 시간 t와 공간 좌표 x에서 영향의 장의 크기와 역학.
- **$E_2(x,t)$** — 장을 이루는 개별 관계들(2성)의 집합.
- **$\partial_t E_2$** (시간 변화율) — 2성 연결 강도가 시간에 따라 변하는 비율. 장의 발생(Genesis)과 쇠퇴(Decay)를 반영한다.
- **$\nabla E_2$** (공간 기울기) — 2성 연결의 공간적 분포 기울기. 장이 공간을 따라 어떻게 확산(Propagation)되고 파동적 특성을 갖는지를 정한다.
- **$\sigma_0(t)$** (근원점) — 영향의 장이 퍼져 나가는 근원점.
- **$\alpha(t)$** (감쇠 계수) — 영향이 거리에 따라 줄어드는 정도.

## 해석

> 객체가 주변에 어떤 영향을 주고, 어디까지 영향을 주는가?

3성은 존재의 파동적 효과를 설명하며, 전자기장·중력장·사회적 파급력 같은 개념에 대응한다.

## 특징과 확장

관계의 총합이 하나의 장으로 작용해 주변에 영향을 끼친다. 감정, 파동, 에너지 흐름 등을 모델링하는 기반이며, 면의 전파에서 더 나아가 4성의 구조적 배치를 이루는 기초가 된다.

정보이론의 읽기에서는 이 장을 정보 흐름의 장으로 보고, 정보 연속식 $E_3(x,t) = \nabla\cdot I(x,t) + \partial I/\partial t$로 쓴다. 여기서 $I$는 정보이며, 식은 '존재의 위상 변화 = 정보의 전이'를 뜻한다. → [정보이론](../interpretations/information.md)
