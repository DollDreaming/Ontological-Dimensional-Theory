# 1성 · 점 (Existence Point)

**객체의 최소 확정 — 있음과 없음.** <span class="st st-def">정의</span>

## 정의

점-객체, 있음/없음, 시간축을 따라 움직이는 최소 단위. 즉 객체가 존재한다는 사실 그 자체를 가리키는 시작점이다.

## 구조적 선언

$$
E_1(t) =
\begin{cases}
1\cdot A(t)\, e^{i\varphi(t)}, & \text{있음} \\
0, & \text{없음}
\end{cases}
$$

- **$E_1(t)$** — 시간 t에서 객체의 존재론적 상태. 궁극적으로 0(없음) 또는 1(있음)이라는 이산적인 값으로 확정된다.
- **$A(t)$** (진폭·세기) — 객체가 존재할 때 가지는 잠재적인 영향력의 최소 크기. 3성(영향의 장)으로 확장될 최소 에너지·세기의 씨앗이다.
- **$e^{i\varphi(t)}$** (위상 인자) — 오일러 공식의 복소수 형태로 나타낸 객체의 최초 정렬 상태 φ. 2성에서 다른 객체와의 공명·상쇄를 결정하는 가장 기본적인 조건이다.

## 해석

> 객체가 있다 vs 없다.

1성은 모든 성의 출발점이다. 단순히 물리적 좌표에 놓인 점이 아니라 "존재 그 자체가 확정되었는가?"라는 질문에 대한 대답이며, 존재의 위상이 정렬되어 변화(시간)를 시작하는 최소한의 조건이다.

## 특징과 확장

1성과 9성은 본질적으로 같은 구조이며, 순환적 프랙탈 구조의 기초를 이룬다. → [연결 구조](../principles/linked-structure.md)

## 여러 분야에서의 대응 <span class="st st-int">해석</span> { data-toc-label="여러 분야에서의 대응" }

| 분야 | 1성의 대응 |
|---|---|
| 물리학 | 플랑크 단위, 양자 상태 결정 |
| 끈 이론 | 0차원 입자 또는 끈의 최소 진동 상태 |
| 정보이론 | 존재의 확정 비트(0/1), 정보의 발생 — 정보 생성(Information Birth) |
| 자아 | "나"라는 자기 존재의 감각(자각점) |
| 학문 | 수학적 존재론, 논리학 |
| 인공지능 | 데이터 입력, 상태 초기화 |
