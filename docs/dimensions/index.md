# 1~9성 한눈에

**존재의 확정 → 관계 → 영향 → 구조 → 통합 → 방향 → 중심 → 반향 → 정의.** 각 성은 앞 성들의 중첩으로 생겨나며, 9성의 정의는 다음 겹의 1성이 된다. <span class="st st-def">정의</span>

| 성 | 이름 | 중첩 → 결과 | 핵심 질문 |
|---|---|---|---|
| [1](1-point.md) | 점 (Existence Point) | 객체의 최소 확정 | 객체가 있는가, 없는가? |
| [2](2-line.md) | 선 (Connection Line) | 점들의 연속적 중첩 → 관계 | 객체와 객체는 어떻게 관계를 맺는가? |
| [3](3-plane.md) | 면 (Field Plane) | 선들의 중첩 → 영향의 장 | 객체가 주변에 어떤 영향을, 어디까지 주는가? |
| [4](4-volume.md) | 입체 (Form Volume) | 면들의 중첩 → 구조 | 객체가 어디에 어떻게 배치되어 있는가? |
| [5](5-multilayer.md) | 다층 (Multilayer Layer System) | 입체들의 중첩 → 통합체 | 객체는 어떤 조합으로 통합적인 의미를 이루는가? |
| [6](6-flow.md) | 방향 (Vectored Flow) | 통합체의 흐름 → 가능성 | 객체가 어떤 방향과 가능성을 향해 나아가는가? |
| [7](7-center.md) | 중심 (Axis of Trace) | 흐름의 누적 → 궤적과 기억 | 객체가 지닌 중심 궤적과 흔적은 무엇인가? |
| [8](8-resonance.md) | 반향 (Resonant Feedback) | 중심의 진동 → 인지와 반응 | 객체가 어떻게 반응하고, 어떻게 투사하는가? |
| [9](9-synthesis.md) | 종합 (Holistic Definition) | 전체 중첩의 귀결 → 정의 | 그 객체는 무엇인가? |

## 수식 읽는 법 <span class="st st-rev">개정 중</span> { data-toc-label="수식 읽는 법" }

각 성의 쪽에 실린 수식은 본편의 **구조적 선언**이다. 수리적 계산을 위한 방정식이 아니라, 각 성의 위상적 관계와 작동 방향을 나타낸다. 차원 증가 원리를 그대로 담는 생성 규칙은 다시 정식화하고 있다. → [열린 과제](../research/open-problems.md#formalization)

## 각 쪽의 구성

- **정의** — 본편이 정한 그 성의 뜻
- **구조적 선언** — 본편의 수식과 변수
- **해석** — 그 성이 던지는 질문
- **특징과 확장** — 다음 성으로 이어지는 방식
- **여러 분야에서의 대응** — 본편 「요약」의 구체적 예시(자아)와 부록 1~5의 대응을 한 표로 모은 것 <span class="st st-int">해석</span>
