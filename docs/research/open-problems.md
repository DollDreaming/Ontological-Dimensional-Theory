# 열린 과제

**수식을 구조적 선언에서 계산식으로 세우는 일, 그리고 저자가 아직 정하지 않은 물음이 남아 있다.**

## 계산식이 정해지지 않은 자리 <span class="st st-rev">열림</span> { #formalization data-toc-label="계산식이 정해지지 않은 자리" }

본편은 아홉 성 모두에 수식의 꼴을 준다. 그중 몇 자리는 연산자의 이름과 성격만 있고, 어떻게 계산하는지는 아직 정하지 않았다. 저자는 지금 수식이 구조적 선언을 넘어서는 단계에 와 있다고 본다(2026-09-24).

| 자리 | 본편에 있는 것 | 열린 것 |
|---|---|---|
| 성 사이의 생성 $\bigoplus$, $\Phi$ | 아래 성들의 위상적 중첩, "단순한 합이 아닌 위상적 누적" | 겹침을 어떻게 계산하는가 |
| 4성의 배열 규칙 $A$ | "단순한 합이 아닌 특정 패턴과 규칙" | 그 패턴과 규칙의 꼴 |
| 7성 | 중심선과 잔흔, 평균·적분은 한 표현 | 중심선과 잔흔을 함께 담는 꼴 |
| 8성의 반영·투사 연산자 $R$ | 7성과 자극의 상호작용 | 반사·투사를 어떻게 계산하는가 |
| 9성의 종합 연산자 $\Omega$ | 처리·해석·압축 | 압축의 꼴 |

→ [핵심 원리](../principles/index.md#topological-accumulation) · [1~9성](../dimensions/index.md)

## 저자가 아직 정하지 않은 것 <span class="st st-rev">열림</span> { #undecided data-toc-label="저자가 아직 정하지 않은 것" }

- 성마다 다른 연산을 쓰는지, 하나의 함수로 이어지는지는 아직 확인할 수 없다. 특수한 경우일 수도 있다고 저자는 본다(2026-09-20).
- 성이 꼭 아홉인지는 확인되지 않았다. 확인되지 않은 것이 틀렸다는 뜻은 아니다(저자 보류, 2026-09-20).
- 7성을 '확정'이 일어나는 자리로 둘지는 정하지 않았다(2026-09-21).
- 성이 한 단계 오를 때의 변화량이 맞는지, 두 가지 프랙탈 무늬가 조합되는 것인지 저자는 묻고 있다.

> "점이 변화하여 선, 선이 변화하여 면 — 이 변화량은 맞는 걸까?" — 저자, 2026-09-20

> "두 가지 프랙탈 무늬가 조합되는 것일까?" — 저자, 2026-09-22

- 에너지란 무엇인가.

> "온도는 에너지이고 내제된 에너지가 증가하면 필연적으로 상호작용이 늘어날수밖에 없다. 그럼 궁극적으로 묻고 싶은것이 있다 과연 에너지는 무엇일까 하는 것이다." — 저자, 2026-09-24

## 이론이 틀릴 수 있는 지점 <span class="st st-hyp">가설</span> { #falsification data-toc-label="이론이 틀릴 수 있는 지점" }

저자는 이 이론의 가장 큰 주장이 곧 이론이 틀릴 수 있는 지점이라고 스스로 밝힌다.

> "9차원 프랙탈 구조로 설명되지 않는 것이 없다. — 이것이 틀릴 수 있는 지점이다." — 저자, 2026-09-21

이 주장이 시험을 견디려면 무엇을 '설명되었다'고 볼지부터 세워야 한다. 저자는 그 기준을 아직 확신하지 못한다고 했다.

## 본편이 제안한 시험 <span class="st st-hyp">가설</span> { #predictions data-toc-label="본편이 제안한 시험" }
