# 시간

**시간은 엔트로피의 변화다.** 바깥에서 흐르는 절대의 축이 아니라, 각 성의 구조가 변할 때 생기는 현상이다. <span class="st st-def">정의</span>

## 본편의 시간해석

기존 시공간 모델에서 시간은 "외부에서 흐르는 절대의 축"이었다. 본편은 시간을 "각 차원 내부에서의 정렬과 반응의 위상"으로 다시 정의하며, 시간은 차원을 관통하는 흐름이 아니라 "차원별 구조가 변화할 때 생기는 현상"이라고 본다.

객체의 배치가 변하고, 존재의 감도가 진폭으로 변하고, 객체의 위상이 이동하기 시작할 때 비로소 시간은 의미를 갖는다.

> 위상이 이동하면서 → 변화가 발생하고,
> 변화가 누적되면서 → 방향이 생기고,
> 방향이 유지되면서 → 흐름이 발생한다.
>
> — 본편 v9.4 「시간해석」

그래서 시간은 "존재의 흐름을 구성하는 위상 정렬의 축"이고, 각 객체는 "시간을 따라 스스로 정렬함으로써 존재하게 되는 흐름적 실체"다. 시간은 성을 넘나들게 하는 접속 고리이자, 존재의 변화·결정·의도·전개를 이끄는 존재론적 매개 변수로 정의된다.

## 다른 분야의 읽기 <span class="st st-int">해석</span> { data-toc-label="다른 분야의 읽기" }

- **물리학** — 시간은 좌표 t가 아니라 위상 변화의 함수 $\tau = \Phi(\Delta\varphi)$이며, 엔트로피는 존재의 위상 불균형 정도로 읽힌다. → [물리학](../interpretations/physics.md)
- **정보이론** — 시간은 엔트로피의 시간 변화율(정렬률)로 읽힌다. 정렬(질서)이 커지면 정보가 압축되어 시간의 흐름이 느려지고, 혼돈(무질서)이 커지면 정보가 확산되어 시간의 흐름이 빨라진다. <span class="st st-hyp">가설</span> → [정보이론](../interpretations/information.md)

!!! warning "현행 읽기 · 개정 중"
    시간은 공간과 나란히 놓인 별도의 축이 아니라, 모든 성에 들어 있는 변화(엔트로피)다. 변화가 없으면 시간도 멈춘 것이다. 본편 부록에서 9성과 시간축을 합쳐 10차원 구조로 설명한 대목은 이 읽기에 맞춰 다시 정리하고 있다.
