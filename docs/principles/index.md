# 핵심 원리

**ODT는 점에서 출발해, 각 성이 앞 성들의 중첩으로 생겨나며 존재의 위상을 넓혀 가는 누적 구조다.** 점이 겹쳐 선이 되고, 선이 겹쳐 면이, 면이 겹쳐 입체가 되듯, 각 성은 앞 성들을 품고 한 단계 올라간다.

## 위상적 누적 <span class="st st-def">정의</span> { data-toc-label="위상적 누적" }

본편은 이 구조를 위상적 생성(topogenesis)이라 부른다. 점이 모여 선이 된다는 기하학적 정의를 넘어, "존재가 자기 자신을 확정하고 연결하고 확장하면서, 그 존재성의 위상이 확장된다"는 뜻이다.

$$
E_n = \bigoplus_{i=1}^{n-1} \Phi(E_i)
$$

- $E_n$ — n성의 존재 상태
- $\Phi(E_i)$ — 아래 성 $E_i$의 위상적 중첩 함수, 곧 i성 존재의 누적·결합 작용
- $\bigoplus$ — 단순한 합이 아닌 위상적 누적(Phase Overlap)

각 성은 이전 성의 결과이자, 동시에 새로운 생성 조건이다.

## 각 성은 독립축이 아니다 <span class="st st-def">정의</span> { data-toc-label="각 성은 독립축이 아니다" }

- 각 성은 새로운 공간의 개방이 아니라, 이전 존재의 심화다.
- 단절이 아닌 누적적 확장이며, 다른 세계가 아닌 더 높은 차원의 자기참조적 구조를 갖는다.
- 각 성은 독립축이 아니라 이전 존재의 중첩으로 생성된 위상 차원이다.

!!! warning "현행 읽기 · 개정 중"
    ODT의 근본 원리는 **기하학적 차원 증가**다. 점 → 선 → 면 → 입체 → … 로 같은 동작이 아홉 번 이어진다. 의식·자아·기억 같은 말은 이 구조를 그렇게 읽은 결과다. 성은 서로 직교하는 축이 아니라, 앞 성을 품고 올라가는 결이다.

## 아홉 단계

본편은 9성 체계를 "존재의 확정 → 관계 → 영향 → 구조 → 통합 → 방향 → 중심 → 반향 → 정의"의 누적적 생성 프랙탈 구조로 이해해야 한다고 적는다. 각 성은 [1~9성 한눈에](../dimensions/index.md)에서 볼 수 있다.
